# DINOv2：无监督学习鲁棒视觉特征（DINOv2: Learning Robust Visual Features without Supervision）解读

> 论文：DINOv2: Learning Robust Visual Features without Supervision（TMLR 2024）
> arXiv：2304.07193｜PDF：papers/10_DINOv2_2304.07193.pdf
> 标签：#DINOv2 #自监督学习 #自蒸馏 #视觉基础模型 #稠密预测 #感知基础

## 一句话总结

把 DINO（图像级自蒸馏）+ iBOT（patch 级掩码建模）+ SwAV 的 Sinkhorn 中心化 + KoLeo 正则组合成稳定的大规模自监督配方，在自动策展的 1.42 亿张无标签图像（LVD-142M）上训练 1.1B 参数的 ViT-g/14，再蒸馏出一族小模型；冻结特征在分类、分割、深度、检索等多类基准上首次全面逼近甚至超过 OpenCLIP 等弱监督特征，尤其以像素级/空间任务见长。

## 1. 研究背景与动机

NLP 的「基础模型」范式（任务无关预训练 + 特征即用）尚未在视觉领域复制成功。原因之一：最有希望的视觉基础模型路线是**文本引导预训练**（CLIP 类），但文本监督有三重限制——caption 只能近似图像信息（细粒度/像素级信息被丢弃）、必须依赖对齐的图文语料、无法从纯图像数据中学习。另一条路是**自监督学习（Self-supervised Learning, SSL）**，理论上更接近语言建模，可同时捕捉图像级与像素级信息；但此前 SSL 的进展几乎都发生在 ImageNet-1k 这个小而精的数据集上，扩展到无策展（uncurated）大数据时特征质量显著下滑——原因是缺乏对数据质量与多样性的控制。

DINOv2 的问题设定因此是：**若在「大规模 + 精选 + 多样」的图像数据上做判别式自监督，能否得到开箱即用的通用视觉特征？** 答案是把既有的 iBOT 系方法在数据与模型规模上放大，同时解决放大过程中暴露的训练稳定性与效率问题。

## 2. 核心贡献

1. **数据**：提出全自动策展管线——不做元数据/文本过滤、不用任何预训练编码器作判别器，而是用「自监督检索 + 聚类 + 去重」从 12 亿张原始网页图像中筛出 1.42 亿张与多个精选数据集分布接近的图像，构建 LVD-142M。
2. **训练配方**：对 iBOT 基线做一系列改造（LayerScale、随机深度、128k prototypes、KoLeo、SwiGLU、patch size 14、teacher momentum 0.994、学习率 warmup 调整、batch 3k、Sinkhorn-Knopp、DINO/iBOT 解绑预测头），并自研高效实现（FlashAttention、序列打包、高效 stochastic depth、FSDP），比 iBOT 实现快约 2 倍、省 1/3 显存。
3. **模型族**：训练 1.1B 参数的 ViT-g/14 教师，并**蒸馏**出 ViT-S/B/L 小模型（蒸馏版全面优于同架构从零训练）。
4. **评测**：在图像分类（ImageNet 及 A/R/C/Sketch 鲁棒性变体、iNat、Places）、实例检索、语义分割、单目深度、视频理解等各种任务上系统评测，多数任务上超过此前最佳 SSL，并在多个任务上逼近或超过 OpenCLIP 弱监督特征；论文同时给出公平性与训练碳排放分析。

## 3. 方法详解

### 3.1 数据管线：无文本、无元数据的自动策展

1. **原始池**：从公开网页抓取 `<img>` URL，过滤不安全/受限域名，下载后做 PCA hash 去重、NSFW 过滤、人脸模糊，得到 **12 亿张**唯一图像。
2. **去重**：用 Pizzi 等的拷贝检测管线去除近重复（增加多样性），并**移除与所有评测集验证/测试集近重复的图像**（防止评测污染）。
3. **自监督检索**：用 ImageNet-22k 上预训练的 **ViT-H/16**（自监督，无文本监督）计算图像嵌入，余弦距离衡量相似度；对无策展数据做 k-means 聚类。给定一个「精选查询数据集」：若查询集大，就为每张查询图检索 N=4 个最近邻（N 再大就会产生多查询命中同一图（碰撞）；4 是检索质量与碰撞的折中）；若查询集小，就从对应聚类中采样 M 张。
4. **工程**：检索与去重基于 Faiss（IVF + 乘积量化，GPU 索引），全部处理在 20 节点 × 8×V100 上不到两天完成，产出 142,109,386 张图像（LVD-142M）。
5. **组成**（表 15）：从 ImageNet-22k（1400 万张原样使用）、ImageNet-1k（检索出约 4100 万张）、各类细粒度数据集（Caltech、CUB、Food、Cars、Flowers 等）、分割/深度/检索数据集（ADE20K、Cityscapes、COCO 类、Google Landmarks、Met、Oxford/Paris 等）按比例混合，兼顾广域覆盖与各域配额。消融证明：LVD-142M 训练的特征在 ImageNet 之外的域（iNat、Places205）显著优于 ImageNet-22k 训练，也明显优于同规模随机采样的无策展数据。

### 3.2 训练目标：自蒸馏 + iBOT + 辅助正则

DINOv2 的目标是 DINO 损失与 iBOT 损失的组合（学生-教师框架，教师是学生的指数移动平均 EMA，momentum 从 0.994 余弦升到 1.0）。自蒸馏能防坍缩的关键在于三点配合：教师看到的是学生看不到的视角（多裁剪非对称输入，迫使学生学到视角不变的表示）、教师分布做中心化/Sinkhorn 归一化（防止所有样本落到同一个原型）、教师由 EMA 缓慢更新（提供稳定的学习目标）。

- **图像级目标（DINO）**：同一图像的不同裁剪分别过学生/教师 ViT，取 class token 送入各自的 DINO head（MLP）得到「原型分数（prototype scores）」，softmax 后计算交叉熵：

$$\mathcal{L}_{DINO} = -\sum p_t \log p_s$$

其中 $p_t$ 是教师分布（softmax 后再做中心化），$p_s$ 是学生分布；只更新学生，教师由 EMA 构造。其「教师读两个大裁剪、学生读一个大裁剪 + 若干小裁剪」的非对称设计使学生学会视角不变性。

- **patch 级目标（iBOT）**：给学生输入随机遮蔽（mask）部分 patch，教师看完整图像；学生把 mask token 经 iBOT head 的输出与教师对应位置（可见）patch token 的输出做同样的 softmax + 中心化交叉熵：

$$\mathcal{L}_{iBOT} = -\sum_{i} p_{t}^{i} \log p_{s}^{i}$$

$i$ 遍历被遮蔽的 patch 索引。这是隐式掩码图像建模（MIM），是稠密预测（分割/深度）能力的来源——消融显示去掉后 ADE-20k 分割掉约 3 个点。

- **Sinkhorn-Knopp 中心化**：对教师分布不用 DINO 原版「softmax + 滑动平均中心」，而用 SwAV 的 Sinkhorn-Knopp 批归一化（迭代 3 次），防止教师坍缩。
- **解绑预测头**：iBOT 论文发现 DINO/iBOT 共享 head 更好，DINOv2 在规模上发现相反——两个独立 head 更好。
- **KoLeo 正则**：鼓励嵌入在 batch 内均匀铺开，取 batch 内最近邻距离：

$$\mathcal{L}_{koleo} = -\frac{1}{n}\sum_{i=1}^{n} \log(d_{n,i}), \qquad d_{n,i} = \min_{j \neq i} \|x_i - x_j\|$$

特征做 L2 归一化后按权重 0.1 施加在第一个全局裁剪的 class token 上（仅在单卡内计算，不做跨卡通信）。消融显示它把实例检索（Oxford-M mAP）提升 8 个点以上，且不伤其他指标——这等价于免费增强特征空间的可分性。

- **分辨率适配**：分割/检测需要高分辨率，但全程高分辨率训练昂贵；DINOv2 在预训练末尾用**短时间把分辨率提到 518×518**（约 1 万迭代），消融证明其效果接近全程高分辨率（416 训练算力约 3 倍于 224，而末尾短程几乎免费）。

### 3.3 高效实现与知识蒸馏

工程改进包括：自研 FlashAttention（更好的显存/速度覆盖）、**序列打包**（把不同长度的大裁剪 224 与小裁剪 98 token 序列拼成一条，用块对角注意力掩码保证等价，避免多次前向）、高效随机深度（随机打乱 batch 后只算前 (1−d)×B 个样本，d=0.4，省下的计算/显存正比于丢弃率）、FSDP 分片（weight 分片存 fp32、通信走 fp16，比 DDP 省约 50% 通信量）。ViT-g 采用 1536 维嵌入 + 24 头（每头 64 维）以最大化硬件效率。整体比 iBOT 实现快 2×、省 1/3 显存。

**蒸馏**：小模型不从零训练，而是以冻结的 ViT-g 为教师、沿用同一训练循环（去掉 masking 与 stochastic depth、iBOT 损失算在两个全局裁剪上、保留学生的 EMA 作为最终模型）。Fig. 5 显示蒸馏版 ViT-L/14 在全部 12 个基准上超过从零训练的 ViT-L/14（如 ImageNet-1k 线性探针 84.5 → 86.3）。

## 4. 数据与训练设置

- **数据**：LVD-142M（142M 图像，自动策展，无标签）。
- **优化**：所有模型训练 625k 迭代；从零训练用 AdamW、lr 3.5e-4、batch 3072、weight decay 0.04→0.2 余弦、warmup 100k 迭代、fp16（DINO head 梯度 fp32）；蒸馏模型 lr 1e-3、batch 2048。LayerScale 初始 1e-5，随机深度 0.4。
- **架构**：ViT-S/14（384 维、6 头、12 层）、ViT-B/14（768/12/18）、ViT-L/14（1024/16/24，从零版用 SwiGLU FFN）、ViT-g/14（1536/24/40，SwiGLU），全部 patch size 14，标称输入 224（评测时再适配不同分辨率）。

## 5. 实验结果与关键消融

- **配方消融（表 1，ViT-L/14 + ImageNet-22k，逐项叠加）**：iBOT 基线 k-NN 72.9 → 我们的复现 74.5 → 加 LayerScale/随机深度 75.4 → 128k prototypes 76.6 → KoLeo 78.9 → SwiGLU 78.7 → patch14 78.9 → teacher momentum 0.994 79.4 → 调度调整 80.5 → batch 3k 81.7 → Sinkhorn-Knopp 81.7 → 解绑头（DINOv2）**82.0**；线性探针 82.3 → **84.5**。注意 LayerScale/随机深度让线性分下降但换来训练稳定性（避免 NaN），是后续增益的前提。
- **损失项消融（表 3）**：KoLeo 把 Oxford-M 检索 mAP 从 55.6 提到 63.9（>8 点），其他指标不降；去掉 iBOT 的 MIM 项使 ADE-20k 线性分割从 47.1 掉到 44.2（≈3 点），印证「图像级目标管检索、patch 级目标管稠密」。
- **数据源消融（表 2）**：INet-22k 线性 ImageNet 85.9 / 开放域偏弱；无策展 142M 仅 83.3 且 Im-A 大跌（59.4）；LVD-142M 为 85.8 / Im-A 73.9 / Oxford-M 64.6——策展数据的收益在非 ImageNet 域最大。
- **主结果（表 4）**：ViT-g/14 线性探针 ImageNet-1k **86.5%**（kNN 83.5），超过 OpenCLIP-G/14（86.2）与 EVA-CLIP-g/14（86.4）；ViT-L/14 达 86.3。ImageNet-V2 78.4（比 EVA-CLIP 高 1.1 点，泛化更好）。
- **鲁棒性（表 6）**：线性探针下 ViT-g/14 在 ImageNet-A **75.9%**（OpenCLIP-G 63.8、iBOT 41.5）、ImageNet-R 78.8（略低于 OpenCLIP 的 87.8）、ImageNet-Sketch 62.5、ImageNet-C 28.2（越低越好）——自然域内偏弱项主要剩「风格化/素描」。
- **微调可选（表 5）**：ImageNet 监督微调后 86.5 → 88.5/88.9，仅比绝对 SOTA（91.1）低 2.2 点，说明冻结特征已「开箱即用」，微调非必需。
- **细粒度与视频（表 7）**：线性探针下 iNat2018 81.6、iNat2021 85.7，大幅超过 OpenCLIP-G/14（73.0/76.0）与 iBOT（66.3/74.6）；视频动作识别 Kinetics-400 78.4（OpenCLIP 78.3）、UCF101 91.2（90.7）、SSv2 38.3（35.8）也全面领先；仅在场景分类 Places205 上略逊（67.5 vs 69.8）。整体模式是：开放世界细粒度分类与视频理解上纯自监督特征能追平甚至反超 OpenCLIP 弱监督特征，风格化图像（Sketch）仍是短板。- **稠密任务**：单目深度（表 11）NYUd RMSE 0.344（OpenCLIP 0.541、iBOT 0.417），KITTI 2.62，NYUd→SUN RGB-D 跨域泛化 0.402——冻结特征 + DPT 解码器即可接近 SOTA；语义分割冻结骨干 + ViT-Adapter/Mask2former 在 ADE20k 达 60.2 mIoU（SOTA 62.9），线性+多尺度在 Pascal VOC 达 86.2（SOTA 89.0），与全量微调的 MAE+UperNet（53.6）在 ADE 线性设置上持平（53.0）。
- **定性**：patch 特征 PCA 第一主成分能阈值分离前景/背景，同一物体不同姿态/风格下对应部件颜色一致（图 1）——这解释了下游任务「线性层就够了」，即**物体部件与场景几何信息显式地存在于特征空间中**。

## 6. 局限性

- 训练成本高：1.2B 图像的策展 + 625k 迭代的 ViT-g，论文专节估计了碳排放；蒸馏虽降低使用门槛，但教师训练仍是重资产。
- 没有语言接口：不像 CLIP 可以做开放词表零样本分类，DINOv2 的特征需要下游数据训练哪怕是线性的探测头；论文把「训练一个把视觉特征当词 token 处理的语言赋能系统」列为未来工作。
- 在部分任务（ImageNet-R、Sketch 等风格/素描变体）仍落后于弱监督的 OpenCLIP；对文本/OCR 类任务无能为力。
- 公平性分析（第 8 节）显示特征在下游任务上的地理与人口统计偏差与数据来源相关；数据和模型都未针对公平性优化。
- 特征质量依赖策展分布：LVD-142M 的查询集选择本身是一种隐性先验，对查询集之外的域（如航拍、医学）未必自动最优。

## 7. 对无人机端到端导航的启示

1. **观测接口**：DINOv2 最契合无人机的价值是**空间/几何理解**——冻结特征上线性探针即可做单目深度、语义分割与物体部件聚类，意味着机载前视单目相机可以同时供给「避障所需稠密深度线索 + 场景语义分割 + 可检索的空地标描述子」。检索能力（实例识别、Google Landmarks 类评测）可复用为视觉地点识别/回环检测的特征后端。与 CLIP 类互补：CLIP/SigLIP 给「这是什么目标」的语言对齐语义，DINOv2 给「在画面哪里、多大、多远」的空间结构。SPOC 的消融给了直接证据：纯自监督的 DINOv2 作为导航视觉底座（44.8%）明显强于 CLIP-RN50（26.6%），但仍弱于图文匹配训练的 SigLIP（49.9%）——**目标条件导航里语义匹配与空间感知都要，选型时按任务权重取舍，或双塔并用**。
2. **动作表示**：DINOv2 不含动作，但作为策略编码器有独特优势——patch 级 token 天然对齐「像素到动作」的空间映射（对比 CLIP 的单一全局嵌入），非常适合把「目标点在图像中的位置」这类空间信号直接喂给动作头（如无人机视觉伺服、目标跟踪飞行的中心偏移量）。其冻结特征「微调可选」的属性还意味着：**换传感器/换机型时可以冻结视觉塔只重训动作头**，降低端到端导航系统的重训成本。
3. **控制频率**：ViT-S/14 与 ViT-B/14 蒸馏版是边缘部署的现实选项（相比 ViT-g 的 1.1B 参数缩小 1–2 个数量级），保留 patch token 输出支持感知-控制回路里「低频全局语义 + 高频局部空间」的分工；若在机载 GPU/NPU 上用 TensorRT 类工具固定分辨率（patch 14 的整数倍），延迟可控。注意分辨率适配的结论：对小型障碍物（电线、细杆），高分辨率输入对稠密任务收益明确，代价按论文经验约 3 倍——无人机安全性场景值得优先投这份算力。
4. **sim-to-real 迁移**：论文的 OOD 定性结果（深度/分割线性头直接泛化到动物画、绘画等完全不同域）说明**自监督特征的域间迁移性可以作为 sim-to-real 的缓冲层**：仿真上训练的探测头在真实图像上不崩，正是无监督特征相对监督特征的卖点。可落地的手段包括：(a) 用「检索策展」思路管理无人机自有数据——以少量精心挑选的航拍/飞行数据集为查询，从海量无标签飞行视频池中自动检索近邻图像构建训练集（LVD-142M 管线的直接类比）；(b) 若要与 SPOC 类管线结合，把 DINOv2 的特征作为「空间分支」拼进目标条件编码器；(c) 保持视觉塔冻结、只做域随机化 + 动作头训练，可避免监督适配破坏特征的域不变性（对照 CLIP 论文的发现：监督适配会吃掉鲁棒性）。
